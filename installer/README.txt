SBCraft - Minecraft inside FNAF: Security Breach
================================================

You need: Windows 10/11, FNAF: Security Breach on Steam, and Minecraft Java Edition (started at least once).

1. Extract this whole zip somewhere you'll keep it (for example Documents\SBCraft). Don't run it from inside the zip.
2. Double-click "Install SBCraft.cmd". It:
     - finds Security Breach on any drive (or asks you for its folder)
     - downloads UE4SS and ReShade from their official sites and installs SBCraft into Security Breach
     - adds Fabric and an "SBCraft" installation to the Minecraft Launcher, with the mod in its own game folder
     - puts a "Play SBCraft" shortcut on your desktop
   Close the Minecraft Launcher and Security Breach before installing.
   If Windows says "Windows protected your PC", click "More info" then "Run anyway" (the scripts aren't signed).
3. Double-click "Play SBCraft" on the desktop. In the Minecraft Launcher pick the "SBCraft" installation and press Play.
   Security Breach starts by itself once Minecraft is ready (in D3D11 mode, which SBCraft needs).
   Leave the Minecraft window open (don't minimize it) and load your save in Security Breach.

Controls (with Security Breach focused): left/right mouse = Minecraft attack/use, wheel or 1-9 = hotbar,
F7 = passthrough on/off, F8 = re-level Minecraft's floor where you stand.

Remove: double-click "Uninstall SBCraft.cmd". Single-player only. Unofficial fan project, built with AI.
Source and full docs: https://github.com/pebbleford/sbcraft
